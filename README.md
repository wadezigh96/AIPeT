# AIPeT 🦊

**Robot Pet Agent** — dari foto anak kucing lembut menjadi companion virtual rubah robot yang membantu user untuk segala keperluan.

*Socialism & Decentralization for pet and human in one place.*  
**Donate · Contribute · Talk with your Robot Pet**

## The Agent

**AIPeT / Rubah** adalah agent virtual robot pet:
- Terinspirasi dari foto anak kucing putih lembut dengan point gelap
- Diubah menjadi **fox-like robot pet** yang ramah dan helpful
- Siap membantu: tanya jawab, saran, perencanaan, curhat, ide, knowledge, dan companionship
